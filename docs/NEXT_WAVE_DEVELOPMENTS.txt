# 🌊 WAVE 1: HARDWARE RESILIENCE, SERIAL KINEMATICS & SENSOR BRIDGING
================================================================================
Priority: P0 (Critical Embodiment Gate)

1.1 Closed-Loop Physical Actuator Calibration & Hot-Plug Auto-Negotiation
    - File: src/robot/motion/serial_bridge.py, src/robot/motion/actuator_guard.py
    - Objective: Replace manual serial initialization with an autonomous hardware
      discovery daemon detecting USB serial controllers (/dev/ttyUSB* or /dev/ttyACM*).
    - Features:
      * Dynamic baud rate negotiation (115200 to 1,000,000 baud) with fallback to emulation.
      * Hardware handshake packet (REQ:PING -> RESP:PONG:FIRMWARE_V2).
      * Automatic zero-motion latch release once physical position packets are verified.
      * Dynamic joint angle range calibration based on microswitch/potentiometer telemetry.

1.2 Real-Time Current & Torque Stall Protection
    - File: src/robot/motion/serial_bridge.py
    - Objective: Continuous 50Hz motor current monitoring to prevent burnout and ensure safety.
    - Features:
      * Immediate soft-compliance trigger if current exceeds 1200mA on any single servo.
      * Audible alert earcon cue (EARCON_ALERT) and dynamic HUD notification upon stall.
      * Automatic return-to-rest trajectory (5th-order minimum-jerk polynomial) upon recovery.

1.3 Physical Expressive Lighting (Aura Sync / USB RGB Integration)
    - File: src/robot/motion/lighting_controller.py
    - Objective: Synchronize physical LED status indicators and chassis lighting
      with active character personality, thinking state, and voice modulation.
    - Profiles:
      * Cyan gentle breathing during IDLE / LISTENING.
      * Rapid pulsing amber shimmer during cognitive reasoning (<thought> streaming).
      * Soft rose / magenta illumination for Luna personality mode.
      * Flashing red strobe during emergency stop or hardware fault.

# 🌊 WAVE 2: MULTIMODAL PERCEPTION, SPATIAL GRAPH & DEPTH ESTIMATION
================================================================================
Priority: P1 (High Impact Intelligence)

2.1 Monocular Metric 3D Depth Estimation
    - File: src/robot/perception/depth_estimator.py, src/robot/perception/engine.py
    - Objective: Deploy lightweight Depth-Anything-V2-Small or MiDaS ONNX model offloaded
      to the AMD Radeon 680M iGPU via DirectML/Vulkan (0MB RTX 3050 VRAM).
    - Features:
      * Compute dense metric depth maps from 320x240 RGB camera frames at 15 FPS.
      * Fuse 2D bounding boxes (YOLOv8n) with depth maps to generate true metric [X, Y, Z]
        coordinates (e.g. coffee_cup at x=+0.25m, y=+0.45m, z=+0.72m).
      * Expose spatial query tool perception.locate_object(target_item).

2.2 Local VLM (Vision-Language Model) Direct Inference Tool
    - File: src/robot/tools/builtins/perception.py, src/robot/llm/local_vlm.py
    - Objective: Enable deep visual question answering through local qwen2-vl-2b-instruct
      with mmproj offload on RTX 3050 or AMD 680M.
    - Features:
      * Tool: perception.analyze_camera_frame(prompt) capturing high-res 720p snapshots.
      * Extract text from physical documents, books, medicine labels, and whiteboard notes.
      * Recognize complex activities (e.g., "Ameya is typing on a keyboard", "Ameya is drinking tea").

2.3 Persistent Face Recognition & Human Re-Identification
    - File: src/robot/perception/face_recognition.py, src/robot/memory/__init__.py
    - Objective: Biometric facial embedding extraction (InsightFace / FaceNet ONNX)
      to recognize known individuals across days without re-introduction.
    - Features:
      * Generate 512-dimensional face embedding on detected YuNet face crops.
      * Match against SQLite known_faces table with cosine similarity threshold >= 0.72.
      * Automatically greet returning users by name with natural conversational memory.

    - File: src/robot/core/context.py

    - Features:
